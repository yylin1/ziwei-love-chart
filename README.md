# 紫微命盤・正緣時機導航

線上紫微斗數排盤工具，包含十二宮命盤、七大人生面向、感情分類查詢與可追溯的年份訊號。

## 線上使用

https://yylin1.github.io/ziwei-love-chart/

## 功能

- 國曆／農曆、時辰與性別排盤
- 十二宮星曜與四化查詢
- 本質、事業、財富、感情、人際、家庭、身心七大分析
- 真命指南、個性相處、出現時機、愛情運勢、幸福建議
- 平衡、核心與寬鬆三種年份口徑
- 全程在瀏覽器內計算，不上傳出生資料

## 說明

排盤核心使用 [iztro](https://github.com/SylarLong/iztro)。結果屬傳統文化與自我探索參考，年份指數是相對訊號，不是事件發生機率。
